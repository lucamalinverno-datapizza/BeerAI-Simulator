# Operating Brewery Control Room 3D

For requests to navigate, demonstrate or operate the simulator, read
[agent_instructions/COMPUTER_USE_GUIDE.md](agent_instructions/COMPUTER_USE_GUIDE.md) before interacting.

It is the computer-use UX/UI operating manual, including third-person avatars, camera recovery,
route planning, every operational panel, scenarios, time playback, save/import/export, comparisons
and the 2D fallback. Adapt its examples to the user's request and verify the current visible state.

Use the visible interface for operating requests. Do not edit the app or inject internal state as
a substitute for computer use. The user's current preferences are Alex, a view from behind and
a wide, readable camera frame; preserve them unless the user asks otherwise.

The manual is not a development or feature-implementation guide. It distinguishes existing
controls from unsupported actions, especially continuous individual-crate loading onto trucks.
